# 大音希声 · 八大山人数字小展

面向第一次了解八大山人的读者。从《荷石水鸟图》看起，再认识朱耷的一生、代表作品和他在书画史上的位置。

## 网站内容

- **首页**从留白、鱼鸟与奇石、以书入画三个角度解读「大音希声」，并简述上海博物馆东馆同名特展的展期、展厅、规模和策展线索。
- **其人**按四个阶段介绍朱耷的生平，附常显的横向年表，从 1626 年至 1705 年列出八个节点。窄屏可横向滑动。另收录两代人的书信对读，以及邵长蘅记载的剪烛笔谈等趣闻。
- **书画作品**收录十二件书画与文献，可按花鸟、山水、书法与手札、人物筛选。作品详情提供全幅或局部图版，可分段读《河上花图》和《鱼鸭图卷》，按开翻阅《书画册》和晚年手札。每次打开详情都从第一张图版开始。本栏还介绍朱耷的书法师承和早、中、晚期的变化。
- **怎么看**以《荷石水鸟图》的全幅与局部为起点，结合《芦雁图》等作品讲解笔、墨、水与构图。
- **书画史地位**介绍清初四僧、写意花鸟画的传承，以及近代画家对朱耷作品的取法、评论与收藏。
- **款识与印章**对照署名、花押和印章，介绍同一花押的两种释读。

所有网站外链均在新标签页打开。涉及故宫馆藏或研究资料时，页面明确标注北京故宫博物院或台北故宫博物院。

## 本地打开

在浏览器中直接打开 [dist/index.html](dist/index.html) 即可使用全部站内功能。网站无需构建或安装依赖。

也可以在项目目录运行以下命令，然后打开 [本地预览](http://127.0.0.1:4177/)。

```powershell
python -m http.server 4177 --bind 127.0.0.1 --directory dist
```

## 文件结构

| 路径 | 内容 |
| --- | --- |
| `dist/index.html` | 页面结构、栏目正文和生平时间线 |
| `dist/works.js` | 作品档案、图版顺序和导览文案 |
| `dist/site.js` | 看画导览、作品筛选、详情及图版切换 |
| `dist/site.css` | 页面布局、时间线和桌面及手机样式 |
| `dist/assets/` | 本地图版与站点图标 |

## 来源

- 网站内容主要依据《大音希声 · 八大山人详解》三卷书稿改写。
- 生平页《个山小像》采用 [八大山人纪念馆著录](https://www.bdsrjng.cn/News_list_1/47.html) 的 1674 年。
- 各作品详情附馆方来源，手札亦附北京故宫博物院释文，《河上花图》附整卷影像页。
- 本地预览图版来自所提供书稿和相应馆方资料。其中切图、印谱与分段影像用于本地预览。对外发布前需逐张核对影像的使用条件。
